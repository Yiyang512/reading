How to Embed French Reading Practice App with Payhip

1. Upload Your Files to a Web Server

Before embedding, make sure all your HTML, CSS, and JavaScript files are uploaded to a web server. You need a publicly accessible URL for your app.

2. Set Up Payhip Embed

Log in to your Payhip account and follow these steps:

  1. Navigate to your product or create a new product
  2. Go to the 'Content' tab of your product
  3. Select 'Add embed content'
  4. Choose 'Embed URL/iframe' option

3. Use This Iframe Code

In the Payhip embed section, use this iframe code (replace YOUR_APP_URL with the actual URL where you hosted the app):

<iframe 
    src="YOUR_APP_URL/index.html" 
    width="100%" 
    height="800" 
    frameborder="0" 
    allowtransparency="true" 
    allow="encrypted-media"
></iframe>

4. Adjust for Responsive Display

For responsive embedding in your website (outside of Payhip), you can use this code:

<div style="position: relative; padding-bottom: 56.25%; height: 0; overflow: hidden; max-width: 100%;">
    <iframe 
        src="YOUR_APP_URL/index.html" 
        style="position: absolute; top: 0; left: 0; width: 100%; height: 100%;" 
        frameborder="0" 
        allowtransparency="true" 
        allow="encrypted-media"
    ></iframe>
</div>

5. Important Notes

  • Your server must deliver the files with proper HTTPS security
  • All files (CSS, JS, images) must be accessible at their relative paths
  • The <base target="_parent"> tag added to your HTML ensures links open in the parent window
  • You may need to adjust the height parameter based on your content
  • Test the embedded app thoroughly on different screen sizes
